**Code:** [github.com/VioletVenti/Klaude-Code](https://github.com/VioletVenti/Klaude-Code) (MIT) · July – October 2026

A terminal coding agent built from scratch. It implements the full set of mechanisms: permissions, hooks, sub-agents, context compaction, memory, multi-agent collaboration, and MCP. The work spans 20 stages, 28 tools, and 155 tests. It also serves as the meta-agent in [recuris-lite](https://github.com/VioletVenti/recuris-lite).
